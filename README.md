# I'm proud of:
💳 BalanceBeacon — Credit Utilization Target Calculation & Score Pattern Analyzer<br>
A backend-focused financial application that analyzes historical credit utilization and credit-score movement to help users better understand their credit usage patterns.<br>
Language: Java 21<br>
Backend: Spring Boot · Spring Security · JPA/Hibernate<br>
Database: PostgreSQL · Flyway<br>
Integration: Plaid<br>
Testing: JUnit · Testcontainers · ArchUnit<br>
DevOps: Docker · GitHub Actions · Maven<br>
Built using a modular backend architecture with session-based authentication, database migrations, automated integration testing, provider boundaries, and deterministic Wilson lower bound utilization analysis.<br>
Repository: This repository is private at the moment.<br>
